
# Requirements

## Functional

- Daily automatic crawling
- Configurable schedules
- Plugin-based source connectors
- OCR for PDFs and images
- LLM-based extraction
- Duplicate detection
- Categorisation
- Geocoding
- Public event submission
- Public source submission
- Moderation queue
- REST + GraphQL API

## Non Functional

- Docker Compose
- Docker Stack
- PostgreSQL
- Redis
- SeaweedFS (S3-compatible object storage)
- Scalable workers
- Health checks
- Logging
- Monitoring
- Tests
- CI/CD
