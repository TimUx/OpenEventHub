# Dokumentationssprachen

> Sprache: Deutsch (primär) · [English](en/DOCUMENTATION_LANGUAGES.md)

## Regel

1. **Primär:** Deutsch — verbindliche Docs liegen unter `docs/*.md`.
2. **Alternativ:** Englisch — Spiegel unter `docs/en/*.md`.
3. Bei Widerspruch zwischen DE und EN gilt die **deutsche** Fassung.
4. Technische Identifier (Services, ENV, Pfade, API-Routen, Metrics) bleiben sprachneutral / englisch wie im Code.

## Banner

Jede Doc-Datei beginnt nach der H1 mit einem Sprachbanner und Link zur anderen Sprache.
