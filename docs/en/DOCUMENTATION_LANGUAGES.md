# Documentation languages

> Language: English · [Deutsch (primary)](../DOCUMENTATION_LANGUAGES.md)

## Rule

1. **Primary:** German — binding docs live at `docs/*.md`.
2. **Alternative:** English — mirrors under `docs/en/*.md`.
3. On conflict, the **German** version wins.
4. Technical identifiers stay as in code.
