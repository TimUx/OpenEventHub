# OCR Pipeline

Supported formats:

- PDF
- PNG
- JPG
- JPEG
- WEBP
- TIFF

Steps

1. File validation
2. OCR text extraction
3. Language detection
4. LLM interpretation
5. Event field extraction
6. Structured JSON output

Output fields:

- title
- description
- start date
- end date
- location
- organizer
- website
- email
- phone
- admission
