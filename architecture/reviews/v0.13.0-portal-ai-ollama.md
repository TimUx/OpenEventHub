# Review — v0.13.0 Portal actions, accents, AI CRUD & Ollama

Date: 2026-08-05  
Scope: Event map/calendar actions, accent theming, Admin AI profile edit/delete, local Ollama default

## Architecture

- Accent themes are CSS `data-accent` tokens with WCAG AA checks in unit tests; no server state.
- Calendar export is client-side `.ics` generation (no new API).
- Map deep-link uses existing MapBrowser selection via `?event=`.
- Ollama runs as infrastructure on `internal` only; Admin still owns provider profiles (ADR 0006).

## Code quality

- Admin AI Settings now calls existing PATCH/DELETE endpoints.
- Seed upserts Local Ollama URL/model without forcing active provider if an operator already chose another.
