# Review — v0.22.0 Import settings & taxonomy filters

Date: 2026-08-08  
Scope: Admin Import-Einstellungen, category import allowlist, curated categories, region hierarchy UX

## Architecture

- Coverage scope and category allowlist are operator ingest filters, separate from region/category catalogs.
- `category_import_allowlist` mirrors `coverage_scope_regions` (singleton set, empty = off, parent expands to descendants).
- Shared evaluators in `@openeventhub/shared`; AI gate in `persistResult` after geo coverage, before event create.
- Curated `DEFAULT_EVENT_CATEGORIES` is seed + alias source; taxonomy still does not invent categories.

## Product

- Operators configure geo and category import filters on one Admin page under Quellen.
- Public browsers use hierarchical region filters (Land → … → Ort).
- DEV helpers: `scripts/repair-dev-regions.sh`, `scripts/reset-categories.sh`.

## Follow-ups

- Heatmap server-side density aggregation if list volume grows past the public API page size.
