# Review — v0.19.0 Admin bulk events, future-only ingest, all-day

Date: 2026-08-06  
Scope: Admin Events bulk status/delete + pending badge; crawl future-only + expired cleanup; `allDay` dates without invented times

## Architecture

- Shared `event-timing` / `temporal-all-day` helpers gate ingest and display; plugins mirror the same rules in plain ESM.
- Scheduler `EventCleanupService` deletes expired rows hourly (cascade via Prisma relations).
- Event/`EventVersion` gain `allDay`; migration backfills UTC-midnight placeholders; ICS uses `VALUE=DATE` for all-day.

## Ops / UX

- Admin Events toolbar for selection + bulk status/delete; edit remains per row.
- Header shows pending-moderation count (Events nav badge + chip).
- Portal/Admin format dates without clock time when `allDay` is true.

## Follow-ups

- Optional bulk API endpoints if selection sizes grow beyond sequential PATCH/DELETE.
- Optional Admin filter to list only `pending_moderation`.
