# Review — v0.18.0 HTML multi-format + Toubiz EMS

Date: 2026-08-06  
Scope: Multi-format HTML listing extraction, embedded Toubiz EMS, per-candidate AI jobs, Admin source edit

## Architecture

- New source types remain plugins only: `plugins/toubiz/` plus shared `plugins/utils/toubiz.js`.
- HTML plugin detects `<toubiz-widget api-token …>` and paginates `mein.toubiz.de/api/v1/events` for **future** dates; expands `dateIntervals` into occurrences; skips canceled.
- When plugins emit events, the crawler enqueues **one AI job per candidate** (short structured text) instead of one LLM call over the full page HTML.
- AI service guard: structured plugin candidates persist even if the model returns `isEvent=false`.

## Ops / UX

- Admin Sources supports edit (name, plugin type, URL, schedule, status); plugin types include `toubiz`.
- Public submit offers `toubiz` as a plugin type.
- Verified live against Rotkäppchenland Veranstaltungen (~400+ future occurrences via Toubiz API).

## Follow-ups

- Additional EMS vendors as separate plugins when encountered (same pattern as Toubiz).
- Optional: EMS-specific rate limiting / caching of API pages.
