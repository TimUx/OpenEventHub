# Review — v0.16.1 Collapsible filters & calendar export

Date: 2026-08-06  
Scope: Quieter portal chrome for list filters and calendar subscribe/export

- No API or feed contract changes; UI-only presentation of existing filter and ICS tools.
- Shared `CollapsiblePanel` keeps secondary tools collapsed by default so the event list stays primary.

- Docs (DE/EN) and screenshots updated to match.
