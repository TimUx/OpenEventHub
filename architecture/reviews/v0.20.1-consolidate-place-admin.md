# Review — v0.20.1 Consolidate, place-from-title, admin chrome

Date: 2026-08-08  
Scope: Multi-source event merge on AI ingest; title-based place inference; Admin branding/nav

## Architecture

- Dedup remains deterministic in `ai-service` (`domain/event-consolidate`): same-source `externalId`, else title+UTC-day + venue compatibility → coalesce fields and link `EventSource`.
- Place inference lives in `@openeventhub/shared` and is applied after LLM extraction; prompts 1.0.2 align wording without replacing the helper.
- Admin branding is build-time `NEXT_PUBLIC_*` only (no runtime secret surface).

## Product

- One logical event per real-world occurrence across sources; thinner source data does not overwrite richer fields.
- Social/public pages stay URL/`html` sources — no OAuth account linking in this release.

## Follow-ups

- Optional LLM tie-break when multiple title matches conflict on the same day.
- Optional long-lived Meta Graph tokens only if public HTML scraping proves insufficient for priority pages.
