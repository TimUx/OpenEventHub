# Review — v0.26.1 Safer venue locality normalize

Date: 2026-08-20  
Scope: Hotfix for over-aggressive `buildingLocalityFromLabel` after v0.26.0

## Architecture

- Strip settlement from `Venue.name` only when (a) an explicit region/classification hint matches a trailing settlement, or (b) the first token is compound `*kirche` (Schlosskirche Ziegenhain → Schlosskirche).
- Street-line address shortening unchanged.

## Product

- Avoids collapsing `Museum der Schwalm` / `Gasthaus Simmen` / `Schloss Hirschgarten` to bare nouns.

## Follow-ups

- DEV DBs that ran the first normalize pass may still have a few unrecoverable short names without region links; re-import or manual rename if needed.
