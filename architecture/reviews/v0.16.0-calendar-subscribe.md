# Review — v0.16.0 Calendar subscribe & bulk ICS

Date: 2026-08-06  
Scope: Multi-event `.ics` download; public iCalendar subscription feed

## Architecture

- ICS generation lives in `@openeventhub/shared` so API and portal stay consistent.
- API exposes `GET /api/v1/calendar.ics` (API First); portal proxies via `GET /calendar.ics` for a same-origin subscribe URL.
- Optional feed query params mirror list filters (`category`, `regionId`, `from`, `to`).
- Bulk download remains client-side over the currently visible event set.

## Code quality

- Unit coverage for shared ICS helpers and frontend feed URL builders; API contract covers feed filtering.
- `PUBLIC_SITE_URL` provides absolute event links inside the feed.

## Follow-ups

- Raise feed page size beyond 100 / paginate large catalogs.
- Optional CalDAV write-back is out of scope (subscribe/import only).
