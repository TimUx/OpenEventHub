# Review — v0.17.0 AI ingest, optional Ollama, Admin ops

Date: 2026-08-06  
Scope: External/optional Ollama, serial crawl schedules, AI event + taxonomy ingest, Admin error log & CRUD

## Architecture

- Compose keeps Ollama behind profile `ollama` (`OLLAMA_DEPLOY`); external stacks join via `docker-compose.ollama-external.yml` and a named Docker network (e.g. `ownai-net`).
- Swarm base stack stays lean; optional `docker-stack.ollama.yml` (+ GPU overlay) mirrors Compose.
- Scheduler registers one BullMQ repeatable job per distinct cron; crawler concurrency 1 processes matching sources serially.
- AI service: prepare/truncate content → extract → optionally create Event + EventSource → classify → find-or-create taxonomy links.

## Ops / UX

- Admin Error log aggregates BullMQ failures, failed crawl jobs, and `Source.lastError`.
- Categories/regions/events are editable in Admin; AI may auto-create taxonomy entries that operators can curate.
- Homepage hero focuses on value + search; brand mark updated (calendar + hub).
