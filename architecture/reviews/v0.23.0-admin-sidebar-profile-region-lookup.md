# Review — v0.23.0 Admin sidebar, profile & region lookup

Date: 2026-08-08  
Scope: Admin chrome sidebar, user edit/self-profile, Nominatim region hierarchy create

## Architecture

- Admin shell uses a fixed left sidebar (240px) with always-expanded nav groups; mobile uses an overlay drawer.
- Self-service profile via `GET|PATCH /api/v1/admin/me` (any authenticated role); password/email changes require `currentPassword` and re-issue JWT.
- Admin user PATCH accepts email/role/password; UI provides explicit Edit beside Delete.
- Region place lookup: sync Nominatim (DE) → hierarchy chain → find-or-create via `from-lookup`. Shared mapper in `@openeventhub/shared`.

## Product

- Operators see all admin sections at once without expanding header groups.
- Every signed-in admin can manage their own credentials under Konto → Mein Profil.
- Creating “Wasenberg” (or ambiguous “Merzhausen”) builds the full Land→…→Ort tree with a candidate picker when needed.

## Follow-ups

- Venue lat/lng geocoding queue still unimplemented (`docs/GEOCODING.md`).
- Optional Nominatim result caching table if admin lookup volume grows.
