# Review — v0.14.0 SEO, PWA & responsive portal

Date: 2026-08-05  
Scope: Search-engine indexability, Progressive Web App, mobile/tablet layout

## Architecture

- SEO stays in the Next.js frontend: `sitemap.ts`, `robots.ts`, `pageMetadata`, JSON-LD (`WebSite`/`Organization`/`Event`).
- Search remains `noindex` and is excluded from the sitemap to avoid thin/filter URL indexing.
- PWA uses the platform Web App Manifest plus a same-origin service worker for shell caching; API and probe routes are bypassed.
- Responsive navigation: bottom tab bar below `lg`, header nav on desktop; safe-area insets for notched devices.

## Code quality

- Crawlable event link lists on calendar/map complement client-only UIs.
- Service worker registration is production-only to avoid Next.js HMR noise.

## Follow-ups

- Optional offline event list cache / background sync.
- Lighthouse CI budget for SEO/PWA scores.
