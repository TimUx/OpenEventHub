# Review — v0.20.2 Coverage scope & flyer-first OCR ADR

Date: 2026-08-08  
Scope: Operator geographic coverage filter; ADR 0007 social/flyer OCR policy

## Architecture

- `CoverageScopeRegion` stores selected region roots; empty set disables the geo filter.
- Shared `evaluateCoverageScope` expands roots to descendants; AI ingest skips new events with a known place outside coverage.
- Taxonomy link order aligned with docs: state → district → municipality.
- ADR 0007 records OCR-mandatory flyer/social ingest without implementing an Instagram plugin.

## Product

- Example: select Schwalm-Eder-Kreis + Alsfeld — all Kreis municipalities are covered without listing them; Alsfeld is an extra root.
- Unknown place still allowed (moderation); known out-of-area places are dropped.
