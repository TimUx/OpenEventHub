# Review — v0.21.0 Event density heatmap (ECharts)

Date: 2026-08-08  
Scope: Public portal Termindichte at `/heatmap` via Apache ECharts

## Architecture

- Classic `/calendar` remains the grid calendar; density lives on a separate route.
- Chart rendered with tree-shaken Apache ECharts (`heatmap` + `calendar`), loaded client-only (same pattern as Leaflet).
- Pure helpers in `heatmap-chart-data` build dense daily series and drill year→month→week→weekend→day.
- Filters reuse list filter helpers (category, region); no API/schema changes.

## Product

- Operators/visitors see busy vs quiet days with zoom and click-to-drill.
- Nav, home feature card, sitemap, and SEO docs include `/heatmap`.

## Follow-ups

- Optional server-side density aggregation if event volume exceeds the public list limit.
- Sync visualMap labels with i18n few/many when customizing legend further.
